# Contributing to the GROWL Catalog

Contributions come from the GROWL Task Force. Everything you need is in
**[GROWL_TF_individual_data_projects/README.md](GROWL_TF_individual_data_projects/README.md)**:

- one folder per dataset, shared by everyone working on it;
- the step-by-step instruction notebooks;
- how to submit your work with a pull request;
- the rules: work only in your dataset's folder, never upload data, every change through a PR.

Questions go to the GROWL Discord, and bring your results to the hands-on sessions.

Reusable code (anything you'd copy between notebooks) belongs in
[growl-tools](https://github.com/growl-lab/growl-tools), not here.
